# VoxelCraft

TypeScript と three.js 製の、ブラウザで動くボクセルサンドボックスゲームです。地形を探索・採掘して道具を作り、町と資源地を道路・鉄道で結んで物流網を育てます。

公開版: https://kamocyc.github.io/claude-web-test-24/

外部画像アセットは使わず、ブロックとアイテムのテクスチャは起動時に生成している。ワールドはシードから決まるため、同じシードなら同じ地形を再現できます。

## 起動

```bash
npm install
npm run dev
```

`http://localhost:5173` を開きます。

## 主な機能

- **探索とサバイバル**: 地形、洞窟、昼夜、敵対・友好的なモブ、体力と満腹度があります。採掘した素材で道具、防具、松明、食料を作れます。
- **クラフトと農業**: `E` のレシピ一覧をクリックしてクラフトします。かまどでの精錬、耕地への灌漑、小麦・ニンジン・ジャガイモの栽培に対応しています。
- **水と地形**: 水はボクセル単位の流体シミュレーションです。水路、貯水、ポンプ、水門を使って地形の水を利用できます。
- **地形のメリハリ**: 町を建てられる広い平地と、海面から 70 マス以上そそり立つ険しい山地がはっきり分かれます。大陸・山脈帯・バイオームはどれも数千マス規模で、山脈を越えるか迂回するかが物流網の設計そのものになります。
- **町と経済**: 町には工場、需要、発展段階があります。原料は資源地のそばに建てる一次産業から生まれ、工場で加工されます。
- **輸送網**: 停留所と路線を登録すると、道の品質に応じて徒歩便・荷車・列車が物資を運びます。道路を舗装・拡幅したり、鉄道を敷いたりして輸送量を改善できます。
- **セーブ**: ブラウザ内への自動保存に加え、ポーズ画面からセーブデータをファイルへ書き出し・読み込みできます。

## 遊び方

1. 木・石・鉱石を集め、`E` のレシピ一覧から道具を作ります。
2. 村を探し、停留所を置きます。
3. `N` の路線表で停留所を順に登録し、道路または線路で接続します。道路だけでは荷物は動きません。
4. 資源の近くに一次産業を建て、町へ原料を届けます。届いた町は発展し、運賃を得られます。

| 操作 | 内容 |
| --- | --- |
| `W` `A` `S` `D` / `Space` / `Shift` | 移動 / ジャンプ / ダッシュ |
| マウス / 左クリック / 右クリック | 視点 / 採掘・攻撃 / 設置・使用 |
| `1`〜`9`、ホイール | ホットバーの選択 |
| `E` | 持ち物・クラフト |
| `N` / `L` | 路線表 / 交易台帳 |
| `H` | ゲーム内ヘルプ |
| `M` | 全画面地図 |
| `Esc` | ポーズ・設定 |

詳しいルール、目標、キー操作はゲーム内の `H` で確認できます。

### 輸送を始めるには

道路を作るだけでは輸送は始まりません。次の4つが必要です。

1. 町または一次産業の近くに停留所を置く。
2. 停留所どうしを通行できる道路、または線路でつなぐ。
3. `N` を開き、停留所を順番に含む路線を作る。
4. `L` の交易台帳で、町が必要としている原料と路線の状態を確認する。

荷物が動かないときは、路線表に停留所が登録されているか、道が途切れていないか、停留所が目的の建物に接続しているかを確認してください。

### 設定とデバッグ

`Esc` のポーズ画面から、難易度、描画距離、マウス感度、コンパス、ミニマップなどを設定できます。開発用には全アイテム無限モードも用意しています。ゲーム中に `F3` を押すと、座標、バイオーム、シードなどの情報を表示します。

## 開発

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

ブラウザを使うスモークテストは、起動済みの開発サーバーに対して実行します。

```bash
npm run smoke
```

経済・輸送部分だけを短時間で確認する場合は、次を使います。

```bash
npm run smoke:economy
```

固定シード `voxelcraft` は地形生成の確認に使えます。ローカルでは `http://localhost:5173/?seed=voxelcraft` を開くと、タイトル画面を経由せずに起動します。

### 公開

`main` ブランチへの push を契機に、GitHub Actions が型チェック、lint、テスト、ビルドを実行し、成功時に GitHub Pages へ公開します。Vite の出力は相対パスを使う設定なので、リポジトリのサブパスでも動作します。

## 構成

- `src/core`: ノイズ、乱数、衝突判定
- `src/world`: 地形、チャンク、光、水シミュレーション
- `src/game`: プレイヤー、クラフト、町、物流、セーブ
- `src/render`: three.js による描画
- `src/ui`: HUD、メニュー、入力
- `src/test`: Vitest テスト

`src/world` と `src/game` は描画ライブラリに依存せず、Node 上でテストできます。

地形生成は「どこに何があるか」を決める低周波のフィールド（大陸度・浸食度・気候）と、「そこがどれだけ険しいか」を決める起伏を分けて組み立てます。浸食度が起伏の**振幅**を変調するので、平地には起伏がまったく乗らず、山地は高さの上限まで使い切ります。詳しくは `src/world/generation/terrain.ts` の `shape()` を参照してください。

地形生成は Web Worker のプールで実行します。描画・メッシュ生成・UI はブラウザのメインスレッド側にあり、ゲームロジックと描画を分離することで、Vitest でロジックを単独検証できる構成です。

### デバッグ用コンソール API

ゲーム中はブラウザのコンソールから `voxelcraft` が使える。

```js
// 例
voxelcraft.give('diamond_pickaxe')   // アイテムを配る
voxelcraft.setTime(0.7)              // 0=日の出 0.25=正午 0.5=日没 0.75=真夜中
```
