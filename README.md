# VoxelCraft

TypeScript と three.js 製の、ブラウザで動くボクセルサンドボックスゲームです。地形を探索・採掘して道具を作り、町と資源地を道路・鉄道で結んで物流網を育てます。

公開版: https://kamocyc.github.io/claude-web-test-24/

外部画像アセットは使わず、ブロックとアイテムのテクスチャは起動時に生成している。ワールドはシードから決まるため、同じシードなら同じ地形を再現できます。

## 起動

```bash
npm install
npm run dev
```

`http://localhost:5173` を開きます。

## 主な機能

- **探索とサバイバル**: 地形、洞窟、昼夜、敵対・友好的なモブ、体力と満腹度があります。採掘した素材で道具、防具、松明、食料を作れます。
- **クラフトと農業**: `E` のレシピ一覧をクリックしてクラフトします。かまどでの精錬、耕地への灌漑、小麦・ニンジン・ジャガイモの栽培に対応しています。
- **水と地形**: 水はボクセル単位の流体シミュレーションです。水路、貯水、ポンプ、水門を使って地形の水を利用できます。板 5 枚でボートを作れば、川や海をダッシュと同じ速さで進めます。
- **川のある地形**: 地形は排水解析で作ります。窪地を埋め、水の行き先を解いて、川が流れる谷を実際に削ります。川は源流から河口まで一本につながっていて、平地では蛇行し、海に注ぎます。町を建てられる広い平地と、海面から 70 マス以上そそり立つ山地の両方があり、平地の多くは川が均した氾濫原です。大陸・山脈帯・バイオームはどれも数千マス規模で、山脈を越えるか迂回するかが物流網の設計そのものになります。
- **町と経済**: 町には工場、需要、発展段階があります。原料は資源地のそばに建てる一次産業から生まれ、工場で加工されます。
- **輸送網**: 停留所と路線を登録すると、道の品質に応じて徒歩便・荷車・列車が物資を運びます。道路を舗装・拡幅したり、鉄道を敷いたりして輸送量を改善できます。
- **セーブ**: ブラウザ内への自動保存に加え、ポーズ画面からセーブデータをファイルへ書き出し・読み込みできます。

## 遊び方

1. 木・石・鉱石を集め、`E` のレシピ一覧から道具を作ります。
2. 村を探し、停留所を置きます。
3. `N` の路線表で停留所を順に登録し、道路または線路で接続します。道路だけでは荷物は動きません。
4. 資源の近くに一次産業を建て、町へ原料を届けます。届いた町は発展し、運賃を得られます。

| 操作 | 内容 |
| --- | --- |
| `W` `A` `S` `D` / `Space` / `Shift` | 移動 / ジャンプ / ダッシュ |
| マウス / 左クリック / 右クリック | 視点 / 採掘・攻撃 / 設置・使用 |
| `1`〜`9`、ホイール | ホットバーの選択 |
| `E` | 持ち物・クラフト |
| `N` / `L` | 路線表 / 交易台帳 |
| `H` | ゲーム内ヘルプ |
| `M` | 全画面地図 |
| `Esc` | ポーズ・設定 |

詳しいルール、目標、キー操作はゲーム内の `H` で確認できます。

### 輸送を始めるには

道路を作るだけでは輸送は始まりません。次の4つが必要です。

1. 町または一次産業の近くに停留所を置く。
2. 停留所どうしを通行できる道路、または線路でつなぐ。
3. `N` を開き、停留所を順番に含む路線を作る。
4. `L` の交易台帳で、町が必要としている原料と路線の状態を確認する。

荷物が動かないときは、路線表に停留所が登録されているか、道が途切れていないか、停留所が目的の建物に接続しているかを確認してください。

### 設定とデバッグ

`Esc` のポーズ画面から、難易度、描画距離、マウス感度、コンパス、ミニマップなどを設定できます。開発用には全アイテム無限モードも用意しています。ゲーム中に `F3` を押すと、座標、バイオーム、シードなどの情報を表示します。

同じ画面の「地図の広域表示」で、歩いていない一帯をまとめて地図に写せます。詳しくは[地形を広く眺める](#地形を広く眺める)を参照。

```bash
npm run typecheck

```

ブラウザを使うスモークテストは、起動済みの開発サーバーに対して実行します。

### 公開

`main` ブランチへの push を契機に、GitHub Actions が型チェック、lint、テスト、ビルドを実行し、成功時に GitHub Pages へ公開します。Vite の出力は相対パスを使う設定なので、リポジトリのサブパスでも動作します。

## 構成

- `src/core`: ノイズ、乱数、衝突判定
- `src/world`: 地形、チャンク、光、水シミュレーション（`generation/infinite` は移植した地形・水文・集落生成）
- `src/game`: プレイヤー、クラフト、町、物流、セーブ
- `src/render`: three.js による描画
- `src/ui`: HUD、メニュー、入力
- `src/test`: Vitest テスト

`src/world` と `src/game` は描画ライブラリに依存せず、Node 上でテストできます。

地形生成は 2 段階です。まず低周波のノイズで素の高さ場を作り、そのうえで水文シミュレーションを走らせます。優先度洪水法で窪地を埋め、流量を集積し、開削できる窪地は開き、平地では流路を蛇行させ、川を掘って氾濫原を均します。地形の平地は多くがこの最後の段で作られたもので、村がそこに立つのもそのためです。

計算は 2 つの解像度で行います。320 マスの粗い格子が広域の海陸と流量を決め、40 マス相当の細かい格子（本作では 1 セル＝16 ブロック）がその内側で本計算をします。どちらも固定の格子に固定の原点で切ってあるので、隣り合うタイルは共有する地面について同じ答えを出します。列の高さは「素の高さ場をブロックごとに評価した値」と「水文処理が加えた差分を格子から補間した値」の和で、こうすると 16 ブロックのセルでも地形が段々になりません。

この地形と、村の立地を決める集落格子は、[kamocyc/ctest105_city_terrain_generator](https://github.com/kamocyc/ctest105_city_terrain_generator) の無限モードからの移植です。移植部は `src/world/generation/infinite/`、セルとブロックの換算は `src/world/generation/scale.ts`、ボクセルへの橋渡しは `src/world/generation/worldField.ts` にあります。町の街区・建物・畑のレイアウトは移植していません（`districts.ts` / `village.ts` / `townBuildings.ts` / `fields.ts`）。

村の場所は、平坦さ・川へのアクセス・海岸へのアクセス・低地度で候補を採点し、半径 R 内で最良のものだけを残して決めます。残った候補は「自分より良い候補までの距離」で村・町・都市に分かれます。畑がどちら側にできるかは微地形（自然堤防・河岸段丘・後背湿地）が決めるので、町の農地はその町の氾濫原を向きます。

地形生成は Web Worker のプールで実行します。校正値と川の閾値だけはワールド全体の性質なので、メインスレッドで一度だけ測ってワーカーに配ります。逆に、メインスレッドは地形タイルを一切組みません — 高さを聞かれたらワーカーが返したチャンクの高さマップを引き、無ければ素の高さ場で答えます。描画・メッシュ生成・UI はブラウザのメインスレッド側にあり、ゲームロジックと描画を分離することで、Vitest でロジックを単独検証できる構成です。

### デバッグ用コンソール API

ゲーム中はブラウザのコンソールから `voxelcraft` が使える。

```js
// 例
voxelcraft.give('diamond_pickaxe')   // アイテムを配る
voxelcraft.setTime(0.7)              // 0=日の出 0.25=正午 0.5=日没 0.75=真夜中
voxelcraft.revealMap(4096)           // 一帯を地図に写す（そのあと M で開く）
voxelcraft.revealing()               // まだ調べている途中か
voxelcraft.forgetRevealed()          // 写したぶんを地図から消す
```

#### 地形を広く眺める

歩いていない一帯を生成器から直接調べて地図に書き込む機能です。海岸線や川の流れ方、
バイオームの分布、村の間隔といった生成の結果を、歩かずに確かめられます。

`Esc` のポーズ画面 →「地図の広域表示」で一辺（512〜10240 マス）を決め、「いま地図に
写す」を押します。コンソールからは `voxelcraft.revealMap(一辺)`（省略時は設定値）でも
同じことができます。書き終わったら `M` で地図を開き、`−` で引くと全体が見えます。

- **裏で少しずつ進みます。** 専用のワーカーで走るので、待つあいだも遊べます。進み具合は
  トーストで 4 分の 1 ごとに出ます。`revealing()` が偽になれば終わりです。
- **広く取るほど時間がかかります。** 費用のほとんどは地形そのもの — 排水解析は 2048
  マスのタイル単位で解くので、覆った面積ぶんのタイルを組むことになります。ワーカー
  3 本での実測は 2048 マス四方で約 7 秒、上限の 10240 マス四方で約 50 秒。面積比ほど
  増えないのは、隣り合うタイルが同じ川の骨格を使い回すためです。
- 標本は 1 チャンクにつき 1 点です。地図を引いた状態では 1 チャンクが 1 ドットなので、
  それより細かく取っても見えるものは増えません。この粗さのおかげで一辺 1 万マスでも
  2MB 弱に収まります。
- 描くのは生成された地面だけで、家やプレイヤーが敷いた道は入りません。歩いた場所の記録
  のほうが優先されます。書いたものはセーブには含まれません（「写したぶんを消す」または
  `forgetRevealed()` で元に戻ります）。
